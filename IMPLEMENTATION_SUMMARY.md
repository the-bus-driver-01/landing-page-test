## How to Use

### For Your First Review

1. **Preparation** (1 week before)
   - Read: `docs/QUICK_START.md` (5 min)
   - Read: `docs/PEER_REVIEW_GUIDELINES.md` (15 min)
   - Prepare: Review scope, select reviewers

2. **Review Execution** (1-2 weeks)
   - Use: `docs/REVIEW_CHECKLIST.md`
   - Reference: `docs/PEER_REVIEW_GUIDELINES.md`
   - Complete: `docs/FEEDBACK_SUBMISSION_TEMPLATE.md`

3. **Collection** (1 week)
   - Add feedback to: `feedback/FEEDBACK_LOG.md`
   - Follow: `docs/FEEDBACK_PROCESS.md` Step 3

4. **Analysis** (1-2 weeks)
   - Use: `docs/ANALYSIS_AND_INSIGHTS_FRAMEWORK.md`
   - Create: Action plans and synthesis report

5. **Discussion** (1 week)
   - Share: Synthesis report with team
   - Discuss: Findings and priorities
   - Align: On action plan

6. **Implementation** (ongoing)
   - Execute: Action items
   - Track: In `feedback/FEEDBACK_LOG.md`
   - Update: Weekly status
